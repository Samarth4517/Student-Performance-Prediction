# 🎓 Student Performance Prediction System

## 📖 Overview

The Student Performance Prediction System is a Machine Learning project that predicts whether a student is likely to pass or fail based on academic and behavioral factors. The system helps identify students who may require additional support and enables data-driven decision-making in educational institutions.

The project uses a Decision Tree Classifier for prediction and provides an interactive web interface built with Streamlit.

---

## 🚀 Features

- Predict student performance (Pass/Fail)
- Interactive Streamlit web application
- User-friendly input form

## 📊 Dataset Attributes

The model is trained using the following student-related features:

| Feature | Description |
|----------|-------------|
| Attendance | Attendance Percentage |
| Study Hours | Number of Study Hours |
| Internal Marks | Internal Examination Marks |
| Assignment Completion | Assignment Submission Status |
| Participation | Classroom Participation |
| Previous Performance | Previous Academic Results |

### Target Variable
- Pass
- Fail

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/student-performance-prediction-system.git
```

### 2. Navigate to Project Folder

```bash
cd student-performance-prediction-system
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

Launch the Streamlit app:

```bash
streamlit run app.py
```

The application will start locally and open in your browser.
